# Nebulynk Product Overview

Nebulynk is a self-hosted communication platform for teams that want control
over their infrastructure, data, and AI-provider choices.

## Product Focus

- Team chat with channels, direct messages, files, search, notifications, and
  role-based administration.
- Voice and meeting workflows, including invitations, guest participation, and
  collaboration features.
- Optional AI-assisted transcription, summaries, and meeting follow-up through
  bring-your-own-key provider configuration.
- Browser and PWA access, with an optional Windows helper for global
  push-to-talk.

## Self-Hosting

Nebulynk is designed for operators who run their own application, database,
object storage, and real-time communication infrastructure. Review the
[secure self-hosting guidance](security-hardening.md) before exposing an
instance to the internet.
